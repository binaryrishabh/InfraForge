# G5 local PostgreSQL sessions

The separately versioned `m2e-pg/1` input selects `postgresql-keyed/1` on relational
resources. Generic `m2e/1`, the first-stack V2 compiler and historical reports keep
their existing keyed profile. Model 2 remains inactive. Timing is assumption-only.
Sources: `packages/simulation/src/model2/data/contracts.ts:13`;
`packages/simulation/src/model2/data/validate.ts:37`.

The finite PG profile owns sessions at pool connection creation, including idle
connections. `maxSessions` means available app-role slots after reservations and
other declared consumers; it is not automatically PostgreSQL `max_connections`.
One session runs one finite plan at a time. Pool acquisition and the authored DB
query admission gate remain separate. That gate is not a PostgreSQL concurrency
setting. Statement timeout starts at command admission; transaction timeout starts
when the finite transaction begins. Zero disables PG timeouts. Lock timeout is per
acquisition. Statement/lock errors and cooperative cancellation roll back the
finite transaction and preserve its session; transaction timeout terminates it.
Interactive BEGIN/error/ROLLBACK protocol states remain unsupported.
Sources: `packages/simulation/src/model2/data/database.ts:21`;
`packages/simulation/src/model2/data/database.ts:41`;
`packages/simulation/src/model2/data/database.ts:94`.

The authored commit interval is explicitly an irreversible commit section. A
cancel or disconnect in that interval cannot undo the commit; the caller outcome
and remote commit are reconciled separately. A detached caller keeps the occupied
pool lease until remote completion. This does not model physical fsync, standby
durability, arbitrary commit subphases or managed HA.
Sources: `packages/simulation/src/model2/data/database.ts:56`;
`packages/simulation/src/model2/network/transport.ts:30`.

The G5 adapter reuses the slice 05 immutable image pins, native-volume capture,
telemetry, archival and LF-normalized hashing. It runs at most one PG container
(1.5 CPU / 2048 MiB, including the separate PgBouncer process) and one probe
(0.5 CPU / 768 MiB), sequentially, with a 180-second campaign watchdog. The
internal bridge has no published port. Disposable trust authentication is fixture
configuration. PgBouncer 1.25.2-r0 is installed separately before network isolation;
its resolved package/runtime receipt is retained. This experiment does not add
pooler support to the simulator. Sources: `g5-manifest.json:7`; `g5-run.ts:70`.

The final record retains five established idle app sessions/two refusals at an
8-slot PG configuration with 2 superuser and 1 reserved slot. A superuser monitor
is closed during app filling and reconnected via a reserved slot. Three repeats
retain SQLSTATE 57014 (statement/cancel), 55P03 (lock), 25P04 (transaction/session
termination), reuse after cancel, lock release on disconnect, and three late writes
after authored caller deadlines. A SyncRep wait intervention retains cancellation
acknowledgement and a surviving committed ID. Separate transaction pooling reuses
one backend after pool waiting. Smart shutdown drains an explicit transaction;
fast shutdown yields 57P01 and rollback. The earlier capture is retained and
excluded from final parity because its short query ended before the fast signal.
Sources: `g5-summary.ts:59`; `docs/reality/g5-local-pilot.json:1`.

These are finite local observations. They do not establish cloud timing, managed
role entitlement, per-query CPU, physical disk latency, full memory or physical
durability. PostgreSQL references: [timeouts](https://www.postgresql.org/docs/18/runtime-config-client.html),
[reserved connections](https://www.postgresql.org/docs/18/runtime-config-connection.html),
[shutdown](https://www.postgresql.org/docs/18/server-shutdown.html).

UI needs only: explicit profile/revision review; app-role capacity and idle/active
sessions; separate pool and DB admission waits; timeout/cancel/session-terminal
reason; caller outcome beside remote commit; immutable input/evidence identity;
assumption-only timing and Unknown physical quantities. No UI design is included.
